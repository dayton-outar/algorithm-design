The mathematical pattern for transforming a sequence of numbers into a matrix is **modular arithmetic used to generate permutations**.

The key idea is: **start with 1, repeatedly add a fixed step, and wrap around when you exceed 5.**

### What the video is doing

It produces these sequences:

| Step | Sequence          |
| ---: | ----------------- |
|   +1 | **1, 2, 3, 4, 5** |
|   +3 | **1, 4, 2, 5, 3** |
|   +2 | **1, 3, 5, 2, 4** |
|   +4 | **1, 5, 4, 3, 2** |

For example, with **+3**:

* Start: 1
* 1 + 3 = 4
* 4 + 3 = 7 → wrap around → **2**
* 2 + 3 = 5
* 5 + 3 = 8 → wrap around → **3**

So:

**1 → 4 → 2 → 5 → 3**

Mathematically, you can express it as:

$$
x_{k+1}=((x_k-1)+s)\bmod n+1
$$

where:

* \(n=5\) = number of items
* \(s\) = the step size
* \(x_0=1\)

### Is there a standard name?

There isn't one single universally dominant name for exactly this procedure, but it is commonly described as a **modular permutation** or **permutation generated by addition modulo \(n\)**.

It's also closely related to an **additive congruential sequence**.

For \(n=5\), the important observation is that the usable step sizes are:

$$
1,2,3,4
$$

because each of those is **coprime to 5**:

$$
\gcd(s,5)=1
$$

That guarantees that the sequence visits **every number exactly once** before repeating.

### General algorithm

For \(n\) numbers:

1. Choose the number of elements \(n\).
2. Choose a starting position/value, e.g. 1.
3. Choose a step \(s\).
4. Add \(s\) to the current value.
5. Apply modulo \(n\) to wrap around.
6. Continue until every element has appeared.
7. If \(\gcd(s,n)=1\), the result will be a complete permutation.
8. Repeat with other values of \(s\) to generate other permutations.

For example, \(n=7,\ s=3\):

$$
1\rightarrow4\rightarrow7\rightarrow3\rightarrow6\rightarrow2\rightarrow5
$$

So this is a very useful technique for **systematically generating permutations without randomly shuffling the numbers**.
